EBELTOFT MARINEFORENING – GPT DEMO V1.1

ÅBN HJEMMESIDEN
1. Pak hele ZIP-filen ud.
2. Behold index.html og mappen assets/img/ sammen.
3. Åbn index.html fra den udpakkede mappe – ikke som en løs fil i en fil-preview.
4. Ved publicering: upload HELE mappestrukturen til GitHub Pages/Vercel.

NYT I V1.1
- Fem billeder skifter hvert 4. sekund med 1,6 sekunders crossfade.
- Pause/afspil styrer skiftet; reduceret bevægelse respekteres.
- Velkomst under hero.
- Diskret bundbjælke viser kommende demo-arrangementer og frivillige opgaver, skifter hvert 7. sekund og kan lukkes.
- Admin > Forside & billeder: redigér velkomst, fem billedstier og beskrivelser.
- Eksisterende bestyrelse, udvalg, aktiviteter, tilmeldinger og dokumenter bevares.

VIGTIGT OM WEBMASTER OG DRIFT
Dette er stadig en DEMO, ikke en sikker administrationsløsning.
- Admin har IKKE login. Alle kan åbne den.
- Ændringer og testtilmeldinger gemmes kun i den lokale browser.
- Billeder skal kopieres til assets/img/ af webmaster; browseren kan ikke publicere filer i denne demo.
- Til rigtig drift kræves en fælles database, login/roller og sikker upload/lagring.
- Brug kun fiktive testoplysninger.

OBS: De viste arrangementer og frivillige opgaver er DEMODATA.
